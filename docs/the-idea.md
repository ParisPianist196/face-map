# The general idea
I want to map user defined facial movements to UI interactions.

## How imma do it
I just like my personal stack of Rust + tauri + Svelte and this is a "fun" project so that's my approach!

## The MVP
I want a desktop app I can use to play my [games](https://www.crazygames.com/) while I walk on the treadmill. 

**Features needed**
- Click
- Click + Drag
- Release
- Move mouse
- Click + hold
