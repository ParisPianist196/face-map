# face-map
Maps face movement to UI interactions. This is experimental! I have grand designs and little ability :D


## Setup tauri
```
cd tauri-app
```

Add the tauri linux dependencies
```
sudo apt update
sudo apt install libwebkit2gtk-4.1-dev \
  build-essential \
  curl \
  wget \
  file \
  libxdo-dev \
  libssl-dev \
  libayatana-appindicator3-dev \
  librsvg2-dev
```

Install Rust
```
curl --proto '=https' --tlsv1.2 https://sh.rustup.rs -sSf | sh
```
